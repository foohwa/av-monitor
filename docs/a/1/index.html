三上悠亜は、日本のアイドル、タレント、YouTuber、元AV女優である。愛知県名古屋市中区出身で、SKE48の元メンバーでもあり、アイドルグループの活動を経て、2015年にアダルトビデオに出演しデビューした。略歴には、アイドルオーディションへの挑戦やグラビア活動、AV女優としての成功が含まれる。彼女は愛称の「ゆあちゃん」や「ゆあにゃ」と呼ばれ、ファンのことを「ゆあーず」と呼んでいる。AV業界に入った理由はチャンスを掴むためであり、女性ファンも多く、彼女のデビュー作の報酬はかなり高額であった。彼女はAV業界のイメージをメジャーに押し上げた功労者の一人であり、自身の売り上げランキングもトップクラスだった。趣味はアイドルのDVD鑑賞や化粧品、語学にも興味があり、ペットを飼っている。友人関係では、元SKE48のメンバーや他の有名人との親交が深く、SNSのフォロワー数も500万人を超えるほどの人気を誇っている。また、バストサロンに通い胸のサイズが成長したことも知られている。
